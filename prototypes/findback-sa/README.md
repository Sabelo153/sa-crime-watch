# FindBack SA prototype

Interactive static prototype for South African community vehicle reporting. Includes fictional sample reports, AI-labelled vehicle illustrations, image galleries, hotspot demonstration data, contact preferences and labelled advertising placements.

This preserves the Sites preview source saved at commit 9f0288ce20d68eaa5d946bf340db37bcd04196e9 on 9 October 2026. It is separate from the Laravel application at the repository root.

Serve the dist directory with any static web server. No build is needed.

Reports, comments, saved items and enquiries are demonstration interactions only. There is no server storage, message delivery, active advertising, payment processing or official SAPS data import. AI imagery must never be presented as evidence of an actual stolen vehicle.

See docs for requirements, design references and advertising/image provenance. Site hosting credentials and local runtime files are excluded.
